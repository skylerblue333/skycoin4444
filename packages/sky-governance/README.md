# SkyGovernance (#145)

Bounded engineering-beta governance decision domain core for Wave 2 Lane 13.

Capabilities: normalized proposal creation, draft/open/closed/cancelled lifecycle, one-vote-per-voter enforcement, deterministic tallies/outcomes, version increments, focused tests, and provider-neutral `sky.governance.decision.v1` integration identifier.

Boundaries: no identity or eligibility verification, token-weighted voting, blockchain execution, treasury movement, legal governance, durable persistence, distributed consensus, production deployment, or compliance guarantee.
