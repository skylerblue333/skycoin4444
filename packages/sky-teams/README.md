# SkyTeams (#130)

Bounded team membership domain core for SKYCOIN4444 Wave 2. It creates deterministic team snapshots, validates roles, prevents duplicate members, and enforces that at least one owner remains.

Integration contract: `sky.teams.snapshot.v1`.

Boundaries: no authentication/authorization enforcement, durable persistence, invitation delivery, directory/SCIM/SAML sync, tenant isolation, audit persistence, billing, or production deployment guarantees.
