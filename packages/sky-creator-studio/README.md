# SkyCreatorStudio (#109)

Bounded engineering-beta creator project domain core.

Capabilities: normalized project creation, immutable version increments, unique asset references, draft-only editing, non-empty publication, terminal/idempotent archival, focused tests, and provider-neutral event contract `sky.creator.project.changed.v1`.

Boundaries: no media upload/hosting/transcoding, live creator distribution, storage service, authorization/tenant isolation, monetization, provider connectivity, production deployment, or compliance guarantee. Asset `sourceRef` values are references only.
