# SkyMentorship

Wave-2 #124 bounded engineering-beta mentorship lifecycle core.

## Capability

Validates mentorship requests, normalizes topic/goals, prevents self-mentorship, enforces deterministic lifecycle transitions, and emits provider-neutral `sky.mentorship.changed.v1` events.

## Boundaries

No credential verification, identity verification, matching/ranking provider, scheduling, messaging, payments, safeguarding workflow, moderation, durable persistence, tenant authorization, compliance certification, or production deployment is claimed. Callers must provide authentication/authorization and any real-world mentor vetting or safety controls.
