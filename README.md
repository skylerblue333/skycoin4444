## Technology Stack

The SKYCOIN4444 platform is built using a modern and robust technology stack:

*   **Frontend:** React, TypeScript
*   **Backend:** Node.js, Express, tRPC
*   **Database:** Drizzle ORM, PostgreSQL
*   **Containerization:** Docker
*   **CI/CD:** GitHub Actions

## Architecture

The platform follows a modular and scalable architecture:

```
client/      Frontend application (React, TypeScript)
server/      Backend services (Node.js, Express, tRPC)
drizzle/     Database schema and migrations (Drizzle ORM, PostgreSQL)
tests/       Automated testing (unit, integration, E2E)
docs/        Technical documentation
.github/     CI/CD configuration and workflows
```
