3. Crypto Risk Management — volatility, position sizing, counterparty risk, liquidity risk, smart-contract risk, scam detection.
4. Smart Contract Security — access control, reentrancy, validation, oracle risk, upgradeability, testing/auditing concepts.
5. Tokenomics & Digital Assets — supply, issuance, emissions, utility, governance, incentives, dilution.
6. Web3 Development Foundations — wallet connection, RPC concepts, signing, contract calls, events, testnets.
7. DAOs & On-Chain Governance — proposals, voting models, delegation, treasuries, governance attacks.
8. NFTs & Digital Ownership — token standards, metadata, provenance, royalties concepts, storage tradeoffs.
9. Layer 2 Scaling — rollups, bridges, data availability, finality assumptions, user safety.

## Definition of done for each course

A course is complete only after it has authored lesson bodies, at least one scored assessment per unit, deterministic answer keys, navigation wiring, learner progress handling, accessibility review, and tests for content loading and assessment scoring. External blockchain interactions should use test/stub adapters unless separately configured and verified.
