# MySQL2 3.23.3 Patch Upgrade

Date: 2026-09-04

## Scope

The canonical SKYCOIN4444 server dependency moves from MySQL2 3.23.2 to 3.23.3.

The manifest changes to `^3.23.3` and the frozen pnpm lockfile resolves exactly 3.23.3.

## Relevant upstream fixes

The 3.23.3 patch includes fixes that directly reinforce the database-pool hardening already present in SKYCOIN4444:

- connection timeout remains active until the MySQL handshake completes;
- each pooled connection receives its own configuration copy;
- pool query-dispatch errors are propagated rather than thrown outside the normal dispatch path;
- the pool replaces its previous external queue implementation with its current internal ring-buffer queue.

The release also includes a named-placeholder behavior fix.

## Lockfile change

The lockfile updates the MySQL2 integrity to the verified 3.23.3 package integrity and removes `denque@2.1.0`, which is no longer a MySQL2 dependency and had no other consumer in the canonical lockfile.

No other direct dependency is intentionally changed by this upgrade.

## Verification boundary

This dependency patch still requires canonical exact-head CI for:

- frozen lockfile installation;
- TypeScript validation;
- package typecheck;
- lint;
- credential and marker scans;
- unit/package tests;
- engineering-beta integration tests;
- production build;
- high-severity production dependency audit.

A green dependency upgrade does not claim a live managed database, external deployment, failover, backup/restore readiness, or production performance certification.
