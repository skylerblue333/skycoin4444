## Baseline and ownership rule

The 1,300 count is a count of **incremental backlog entries**, not a count of already implemented capabilities.

- Gaming, Social, and HopeAI are under active redesign and are not duplicated here.
- Core Chat/Messaging/Video/Live transport, calling, playback, live-room mechanics, streaming/transcoding, and real-time chat are excluded. Area 5 contains only creator-side authoring, publishing, packaging, moderation-policy, analytics, and bounded integration work layered on those engines.
- The existing Dating beta baseline—profile setup, discovery, likes/super-likes/passes, mutual matches, and match messaging—is not counted. Area 6 starts with incremental capabilities beyond that documented baseline.
- Wave-2 SkyJobs/SkyTalent/SkyMentorship domain cores are not counted. Area 3 starts with user-facing, persistence, workflow, scheduling, employer/candidate, and mentorship integration work beyond those cores.
- SkyShop supplier discovery V2, merged in PR #406, already owns its own truth-labeled 100-capability marketplace expansion map. Marketplace/Commerce is therefore **not duplicated in this Wave-3 count**.
- If any other backlog entry is later found to already be fully satisfied by verified canonical implementation, mark it baseline/complete and replace it with genuinely incremental work before preserving the advertised count.

## Rules

- Every numbered line is **planned** until meaningful implementation and release evidence exist.
- Financial, custody, trading, live blockchain, identity-proofing, employment-decision, and external-provider capabilities remain test, read-only, simulated, human-reviewed, or unavailable until independently verified.
- Every implementation should include validation, authorization, deterministic behavior where applicable, tests, error handling, accessibility, privacy/security boundaries, documentation, observability, rollback, and truthful capability labels.
- Promotion to beta must follow `BETA_SCOPE.md`, `BETA_RELEASE_CHECKLIST.md`, the mission-control catalog, and the area readiness matrix.
